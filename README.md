# 싸카 (SSAKA / 싸바카드)

앱 설치 없이 카카오톡 링크 한 번으로 열리는 인터랙티브 모바일 웹 카드.
통화 · 길찾기 · 연락처 저장 · 복사 · 예약, 그리고 "어디야?"까지.

브랜드 색: 싸카 체리 레드 `#F23A4E` (작은 흰 글씨용 진한 루비 `#D9283F`)

## 무엇을 할 수 있나

- 카드 만들기: 업종 17개 × 디자인 12개(총 192개), 6가지 스타일(시네마·포스터·글래스·매거진·스티커·티켓 + 안심)
- 대표 사진·간판 사진 올리기, 우편번호 찾기, 필수 칸 안내와 완료 바
- 보내기: 카카오톡 공유(무료) · 문자(전화번호부에서 선택) · 링크 복사
- 받는 쪽 버튼: 바로 통화 · 길찾기(카카오맵/네이버) · 연락처 저장(카톡 안에서도) · 복사 · 예약
- 가게 예약: 날짜·시간·인원·메뉴 → 예약 문자, 4명 이상 예약금(20%) 계좌, 예약번호로 취소
- 소리: 열자마자 "안녕하세요!"·"어디야?"·사투리·찐친 장난 등 26종, 소리 없음 가능
- 메인 화면: 내가 만든 카드 · 받은 카드 · 예약 모아보기, 홈 화면에 추가하면 앱처럼 실행
- 어디야?: "여기로 와!"(약속 장소·시간·지도·길찾기·빠른 답장) / "어디야?"(버튼 하나로 내 위치 답장)

## 폴더 구성

```
ssaka-app/
├── index.html            # 주경중 감독 카드 (배너 이미지 + 투명 버튼)
├── bg2.jpg, joo.vcf      # 감독 카드의 이미지·연락처
├── manifest.webmanifest  # 홈 화면에 추가 (앱 아이콘)
├── app/                  # 싸카 메인 화면
├── make/                 # 카드 만들기
├── c/                    # 만든 카드를 여는 화면 (c/?d=카드내용)
├── eodiya/               # 어디야?
├── demo/                 # 예시 카드 + 카드 화면 동작(js/card.js, js/vcard.js)
├── css/
│   ├── brand.css         # 싸카 브랜드 색
│   └── sk.css            # 카드 디자인 스타일 (모든 규칙이 .sk 안에서만)
├── js/
│   ├── designs.js        # 업종·디자인 192종 자동 생성, 글자 대비 자동 보정
│   ├── render.js         # 카드 그리기 (카드 화면·만들기 미리보기 공용)
│   ├── codec.js          # 카드 내용 ↔ 링크 변환 (서버 없음)
│   ├── share.js          # 카톡 공유(카카오 JS 키), 문자 보내기
│   ├── inapp.js          # 카톡 안 브라우저 대응 (연락처 저장 시 사파리·크롬으로)
│   ├── reserve.js        # 예약
│   ├── sound.js          # 소리 (목소리·효과음)
│   └── store.js          # 이 휴대폰에 저장되는 기록 (만든·받은 카드, 예약)
├── img/                  # 앱 아이콘, 공유 이미지
└── docs/                 # 사업계획 · 기술 스펙 · 로드맵
```

## 알아둘 점

- 서버가 없어서 비용 0원. 카드 내용은 링크 안에 들어 있고, 기록은 각자 휴대폰에만 저장됩니다.
- 카카오디벨로퍼스 앱 이름을 "싸카"로 바꾸면 카톡 카드 아래 출처가 싸카로 나옵니다.
- 카톡 미리보기가 안 바뀌면: 카카오디벨로퍼스 → 도구 → 카카오톡 URL 메타정보 관리 → 캐시 초기화
