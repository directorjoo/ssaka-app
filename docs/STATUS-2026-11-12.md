- 번호·이메일 일체 비공개: 배우도 캐스팅 디렉터도 올릴 수 없음(010, @, 오픈채팅, 인스타 아이디 자동 차단).
- 오디션 흐름:
  1차 서류·이미지(싸바스타 안) → 2차 영상(유튜브 일부 공개 링크) → 3차 지정 장소 현장 연기(이름으로 확인, 참석·불참은 서버 경유)

  현장에서 명함 주고받는 건 막지 않음.
- 3차 초대 카드 자동 문구: 공고에 적힌 장소·시간에만 오디션, 따로 만남·돈 요구는 신고. 3차 장소는 공고 때 필수.
- 볼 자격: 배우가 고름(링크로만 / 관계자에게만(기본) / 전체 공개). 관계자 = 카카오 로그인 + 소속·작품 + 용도 동의(심사 없음).
  하루 열람 수 제한, 사진에 작은 "싸바스타" 표시, 누가 봤는지 기록 안 함. 만 19세 이상만.
- 신뢰 장치(자동): 디렉터 팔로우(새 공고 알림), 디렉터 공개 프로필(진행·완료한 오디션 수),
  3차 후 "공고대로 진행됐나요? 예/아니오" 한 문항 → 비율만 표시, "아니오" 많으면 새 공고 자동 보류.
  신고 3번이면 자동 숨김, 감독님은 숨겨진 것만 일주일 10분 확인.
- 자동 정리: 공고는 마감일 지나면(없으면 30일) 내려감, 오디션 기록은 발표 30일 뒤 삭제, 1년 안 고친 프로필은 알림 후 숨김.
- 알림: 번호가 없으니 카카오 로그인 "메시지 보내기" 권한으로 배우 본인 카톡에 알림 (17일에 카카오 조건 확인, 안 되면 "내 오디션" 화면).
