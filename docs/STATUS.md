## 3. 남은 일 (우선순위 순)
1. 현대·롯데백화점 홈 벤치마킹으로 홈부터 모든 화면 다시 꾸미기 — 파스텔 표준 색, 체리 모양 탭, 글씨 크기·글씨체 (대표님이 캡처 보내기로 함)
2. 싸바카드 만들기 흐름 개편: 용도 고르기 → 디자인 고르기 → 쭉 쓰고 "완성" → 다른 디자인·색 비교 → "최종 결정하세요?" → 미리보기 → OK → 체리 팡파레
   - 입력 칸은 용도에 맞는 것만 나오게, 한 번 쓴 정보는 저장해서 다시 사용
   - 완성 뒤 "다른 용도(올릴 곳)도 만들까요?" 물어서 반복
3. 싸바알림 카드 디자인 새로 짜기 — 올릴 곳에 카톡채널·인쇄(전단·포스터) 추가, 부고·결혼은 일단 빼기
4. 카톡 큰 글씨 대응 — 큰 글씨일 때 긴 설명 대신 짧은 한 줄
5. 여기야 받는 화면의 "아무 데나 탭하세요" 덮개(소리 때문에 두 번 누르게 됨) 고칠지 대표님 확인 필요 — eodiya/index.html playSound()

## 4. 홈 개편 분석 (2026-11-21, app/index.html 실제 화면 기준)
- 답답한 이유: 첫 화면에 카드 5장·단추 6개·색 6가지(빨강·초록·파랑·갈색·금색·노랑), 카드 사이 약 12px, 진한 그림자·금 테두리·이모지 많음, 맨 위 큰 동그라미 3개(새 버전·언어·설정)
- 고칠 방향: 한 화면에 큰 카드 1장(화면의 80%), 카드 사이 40px, 구역 제목 26px 검정, 카드마다 단추 1개, 카드 1장에 12색 중 1개, 사진은 위·글칸은 아래, 맨 위는 날짜·날씨 한 줄 + 설정 1개, 아래 탭은 떠 있는 알약(체리 1색)
- 새 홈 순서(제안): 1 맨 위 날짜·날씨·"싸바" → 2 어디야(12번, 단추 "열기" 하나) → 3 싸바알림(4번, "1분에 만들기" 하나) → 4 지금 보내기 좋은 카드(정사각 넘김, 그대로) → 5 오늘의 싸바(2번) → 6 오늘의 놀이터(10번) → 7 특판 코너(11번, 알림판에서 분리) → 8 블로그 쓰기(6번)/싸바비앙(1번+금 왕관) → 9 싸바 이야기(3번)
- 결정(11-21): 홈 어디야 칸에 싸바?·여기야!·놀자! 세 단추를 몰아 넣고, 어디야 화면의 탭 줄(중간 고르기)은 없앰 — 홈에서 누르면 바로 그 쓰는 칸. 시·음악 액자는 쓰는 칸 맨 위 그대로. 어디야 카드만 "단추 1개" 원칙의 예외
- 색·크기는 아직 안 바꾸고 위치만 옮김 → 11-21 00:20 묶음보내기로 sava.kr에 올림 (버전 2026.11.21-262, sw sava-v237). 해시 없이 /eodiya/ 로 열면(받는 사람의 "나도 보내기" 등) 탭 줄은 그대로 나옴
