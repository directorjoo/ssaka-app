## 2. 정해 둔 색 (표준 색)
- 브랜드: 체리 레드 #B3132B
- 홈 블록: 어디야 = 체리 빨강(물방울 체리 사진 확대), 싸바알림 = 초록, 블로그 쓰기 = 도서관 아치 책장 사진, 싸바비앙 = 라파예트 돔 황금색(검정 절대 금지)
- 기준 색: 오방색(청·적·황·백·흑), 한 화면엔 2~3색만
- 바탕: 단색 금지, 백화점·앱스토어처럼 연한 그라데이션
- 백화점 파스텔 12색: (이전 방에서 정리한 목록을 여기에 붙여 넣을 것 — 아직 비어 있음)
- 글씨: 흰 글씨엔 검은 그림자, 진한 글씨엔 흰 그림자 / 노랑은 신호등 노랑 / 설명 글씨는 최소 11~12pt

## 3. 남은 일 (우선순위 순)
1. 현대·롯데백화점 홈 벤치마킹으로 홈부터 모든 화면 다시 꾸미기 — 파스텔 표준 색, 체리 모양 탭, 글씨 크기·글씨체 (대표님이 캡처 보내기로 함)
2. 싸바카드 만들기 흐름 개편: 용도 고르기 → 디자인 고르기 → 쭉 쓰고 "완성" → 다른 디자인·색 비교 → "최종 결정하세요?" → 미리보기 → OK → 체리 팡파레
   - 입력 칸은 용도에 맞는 것만 나오게, 한 번 쓴 정보는 저장해서 다시 사용
   - 완성 뒤 "다른 용도(올릴 곳)도 만들까요?" 물어서 반복
3. 싸바알림 카드 디자인 새로 짜기 — 올릴 곳에 카톡채널·인쇄(전단·포스터) 추가, 부고·결혼은 일단 빼기
4. 카톡 큰 글씨 대응 — 큰 글씨일 때 긴 설명 대신 짧은 한 줄
5. 여기야 받는 화면의 "아무 데나 탭하세요" 덮개(소리 때문에 두 번 누르게 됨) 고칠지 대표님 확인 필요 — eodiya/index.html playSound()
