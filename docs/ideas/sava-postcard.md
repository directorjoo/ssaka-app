# 싸바카드 = 엽서 문자 (2026-11-23 대표님과 정한 방향)

> 한 줄 정체성: **"한마디를 엽서로 보내세요."**
> 카톡은 '빠른 말', 싸바카드는 '받으면 기분 좋은 말'. 카톡과 속도로 싸우지 않고 품격으로 싸운다.

## 1. 대표님이 정한 것 (바꾸자고 다시 꺼내지 않기)
- 이용자마다 **자기 엽서 디자인을 미리 정해 둔다** → 보낼 땐 글만 쓰면 그 엽서에 담겨 나간다.
- ⭐ **속도가 생명**: 그림엽서를 보내는 속도가 글만 보낼 때와 같아야 한다. 느려지면 이 엽서 문자는 실패.
- **포지셔닝: 짧은 인사 위주, 예의와 성의를 보이는 인사.** (안부·감사·"잘 들어가셨지요?"·명절·생일) 매일 "어디야/ㅇㅋ" 같은 잡담은 카톡에 맡긴다. 매번 엽서가 오가면 지친다.
- **크기: 가로 4:3, 옛날 엽서 비율.** 대화방에서 너무 크면 앞 대화가 밀려 부담스럽다 — 크게 보이는 것보다 대화 흐름을 덜 가리는 게 우선.
- **엽서 형식 그대로**: 앞면 그림, 뒷면 글·우표·주소 칸. 디자인·글씨 배치는 얼마든지 바꿀 수 있게.
- 이름: **싸바카드** (엽서 문자).

## 2. 보내는 흐름 (목표: 글 쓰는 시간 빼고 5초, 누르는 건 3번)
1. 싸바 열기 → 바로 글 칸 (내 엽서가 이미 깔려 있음, 디자인 고르기 단계 없음)
2. 글 쓰기 (한 줄 인사 칩도 옆에)
3. [보내기] → 카톡 친구 고르기 → 보냄
- 카톡 안에서 바로 치는 것보다 친구 고르기 한 단계(3~5초) 더 걸리는 건 어쩔 수 없음. 줄이는 법: 자주 보내는 사람 기억, 홈 화면 첫 줄에 싸바.
- 받는 이 호칭 고르기: "께 / 님께 / 에게", 보내는 이: "올림 / 드림 / 가" — 어른·친구·아이에 맞게 (한 번 톡).

## 3. 받는 사람 화면
### 카톡 말풍선 미리보기 = 엽서 앞면
- 내 엽서 그림 + 첫마디 한 줄(10자 안팎, 크게). 긴 글은 미리보기에 넣지 않는다 — 작아서 안 읽힘.
- 비율 4:3 (예: 1000×750). ✅ 카카오 기준: 가로 2:1 ~ 세로 3:4 범위 안이면 잘리지 않음(벗어나면 가운데 잘라냄), 파일 2MB 이하, 200×200 이상 — 4:3은 안전. (출처: devtalk.kakao.com/t/v2/33492)
- ⚠️ js/share.js 주석엔 "카톡이 가운데를 정사각형에 가깝게 자른다"는 예전 경험이 있음(어디야 그림은 1000×600으로 씀) → 만들 때 실제 아이폰·안드로이드 카톡에서 4:3이 안 잘리는지 꼭 시험.
- 말풍선 아래 단추는 하나만("엽서 열기"), '싸바카드 설치하기' 단추는 빼서 광고 느낌 없게 (SAVA_QUIET).

### ❌ 11-25 대표님: 뒤집기 취소 — 받은 말은 '툭' 튀어나오기만, 대신 답장 칸을 예쁘고 다르게 (아래 뒷면 내용은 참고로만 남김)
### (취소됨) 누르면 = 엽서가 뒤집히며 뒷면 (0.5초, 다시 누르면 앞면)
- 왼쪽: 손글씨 느낌 글꼴로 인사 전체
- 오른쪽 위: 우표(매번 다른 작은 그림 — 모으는 재미) + 소인 "2026.11.23 여수"(날짜·보낸 곳 시/군)
- 오른쪽 아래: 밑줄 친 주소 칸 모양 — "OO 선생님께" / "OO 올림"
- 맨 아래: [✉️ 엽서로 답장하기] → 받은 사람은 기본 엽서로 바로 답장 → 그다음 "내 엽서 꾸미기"로 이어짐 (퍼지는 고리)
- 큰 글씨 필수 (어르신이 안경 없이 읽게). 가볍게: 글씨 먼저 그리고 그림은 뒤에, 1초 안에 뜨게.

## 4. 속도를 지키는 기술 방법 (가장 중요)
이미 있는 길: make/index.html이 캔버스로 공유 그림을 그려 `Kakao.Share.uploadImage`로 올리고(6초 넘으면 대표 사진으로 보냄), js/share.js가 `Kakao.Share.sendDefault(feed)`로 imageUrl·imageWidth·imageHeight를 지정해 보냄. → 엽서도 이 길을 그대로 쓴다.
- **A안(기본): 쓰는 동안 미리 그려 미리 올리기.** 글 칸에 입력이 멈추면(0.8초) 폰 캔버스가 '내 엽서 + 첫마디' 4:3 JPEG를 그려 uploadImage로 미리 올려 둠 → [보내기] 땐 이미 주소가 있어서 기다림 0. 글이 바뀌면 다시 올림(마지막 것만 씀).
- **B안(늦을 때 안전망): 글 안 박힌 엽서 그림.** 내 엽서 그림 자체(글 없는 앞면)는 엽서를 정할 때 한 번 올려 주소를 기억 → 미리 올리기가 안 끝났으면 이 그림 + 말풍선 제목(title)에 첫마디로 즉시 보냄. 절대 기다리게 하지 않는다.
- 서버(Cloudflare)에서 그리는 방법도 가능하지만 한글 글꼴·속도 부담 → 폰 캔버스가 먼저.
- 문자 내용은 지금 카드처럼 링크 안에 담기(c/ 방식) → 서버 저장 거의 없음, 서버비 0 유지. 링크 미리보기(문자·아이메시지)는 functions/eodiya처럼 og 태그 바꿔 주기.

## 5. 엽서 디자인 (고를 건 적게)
- 엽서 틀 6~8가지 + 손글씨 글꼴 2~3가지만. 많으면 50~70대가 처음 정하다 지침.
- 색은 정해 둔 체리 레드 #B3132B + 미색 바탕 안에서. (DESIGN 고정 제안과 같게)
- 내 엽서 최대 3장 (어른용·친구용·아이용), 보낼 때 한 번 톡으로 바꿈. 기본은 늘 쓰던 한 장.
- 계절이 바뀌면 같은 디자인에 배경만 저절로 봄·여름·가을·겨울로 (선택).
- 예시 글·이름에 "주경중" 절대 쓰지 않기.

## 6. 성공 재는 숫자
- 보내기 버튼 누른 뒤 카톡 창 뜨기까지 시간 (목표 1초 안)
- 받은 사람이 링크 여는 비율, **엽서로 답장한 비율** ← 핵심
- 내 엽서를 꾸민 신규 이용자 수

## 7. 만드는 순서 (첫 단계 3가지)
1. 내 엽서 정하기 화면 (틀·글꼴·호칭, 이 폰/계정에 저장, 앞면 그림 미리 올려 두기)
2. 글만 쓰고 보내기 (A안 미리 올리기 + B안 안전망, 4:3 피드 공유)
3. 받는 화면: 받은 말이 툭 튀어나오기(뒤집기 취소 11-25) + 예쁜 답장 칸
- 그다음: 우표 모으기, 계절 배경, 3장 엽서, 답장 통계
