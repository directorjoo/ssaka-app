싸바 개인정보처리방침

시행일: 2026년 11월 9일

싸바는 지금 회원가입이 없어요. 여러분이 카드나 "어디야?"에 적은 내용은 여러분의 휴대폰과 여러분이 보낸 링크 안에만 있어요. 서버에 두는 건 두 가지예요. "나도!" 모으기에 동의하고 적은 이름(닉네임)은 출발하면 바로 지워요. 그리고 카톡으로 보내려고 만든 카드의 짧은 링크(카드에 공개하려고 적은 내용)예요. 위치는 서버에 저장하지 않아요.

1. 어떤 정보가 어디에 있나요

정보어디에 있나요누가 보나요
카드에 적은 이름·전화번호·주소·계좌·사진 주소카드 링크 안, 내 휴대폰 브라우저 저장소링크를 받은 사람
"여기야!" 위치보낸 링크 안 (버튼을 눌렀을 때만 위치를 확인해요)링크를 받은 사람. 24시간이 지나면 화면에서 숨겨요
예약·참석 답장손님 휴대폰 문자앱·카카오톡으로 직접 전송가게·모임 연락처 주인
카드에 올린 사진카카오 이미지 서버 (일정 기간 뒤 자동 삭제될 수 있어요)링크를 받은 사람
"나도!" 모으기 참가 이름(닉네임)과 모임 정보(놀이 종류·장소 이름·시간)싸바 서버(Cloudflare D1). 동의 체크를 한 사람만 저장돼요같은 초대장을 연 사람. 모으는 사람이 출발하거나 취소하면 즉시 삭제, 출발 안 한 모임은 24시간 뒤 자동 삭제
게임 기록 (럭키 7초 체리, 파리 잡기 등급, 당구 선수 이름)내 휴대폰 브라우저 저장소에만나만. 도전장을 보내면 그 기록이 링크에 들어가요
싸바카드 짧은 링크용 카드 내용(카드에 공개하려고 적은 제목·소개·연락처·메뉴 등)싸바 서버(Cloudflare D1). 카톡·문자로 보내기를 누르면 저장돼요(카톡이 긴 링크를 받지 않아서)링크를 받은 사람. 삭제를 원하면 운영자에게 요청
블로그 글 만들기에 쓰는 카드 내용Anthropic(미국)의 AI로 보내 글을 쓰고, 싸바 서버에는 글을 저장하지 않아요. 하루 사용 횟수를 세는 기기 임의번호만 그날 하루 보관본인
방문 통계Cloudflare 웹 통계 (쿠키 없이, 개인을 알아볼 수 없는 방문 수만)싸바 운영자

2. 꼭 알아 두세요

  • 카드 링크는 받은 사람이 다른 사람에게 다시 보낼 수 있어요. 주민등록번호, 카드번호 같은 민감한 정보는 적지 마세요.
  • 싸바 카드 링크는 검색엔진(구글·네이버)에 나오지 않도록 막아 두었어요.
  • "나도!" 모으기에 넣은 내 이름은 "빠질래요"를 누르면 그 자리에서 지워져요.
  • 휴대폰에 저장된 내 카드 기록은 브라우저의 "방문 기록 및 데이터 지우기"로 언제든 지울 수 있어요.

3. 함께 쓰는 서비스

  • 카카오: 카카오톡 공유, 사진 올리기, 장소 검색
  • Cloudflare, Inc.(미국): 사이트 전송, 방문 통계, "나도!" 모으기 이름 보관. 서버가 해외에 있을 수 있어요(국외 이전: 참가 이름·모임 정보 / "나도!"를 누를 때 인터넷으로 전송 / 출발 즉시, 늦어도 24시간 안에 삭제). 동의하지 않으면 "나도!" 모으기만 못 쓰고, 다른 기능은 그대로 쓸 수 있어요.
  • Anthropic, PBC(미국): "블로그 글 만들기"를 누를 때만 카드 내용을 보내 글을 써요(국외 이전, 글을 돌려받으면 싸바는 보관하지 않음). 이 버튼을 누르지 않으면 보내지 않아요.
  • 지도: 카카오맵·네이버지도·오픈스트리트맵 (길찾기 버튼을 눌렀을 때)

4. 앞으로 바뀌는 점

회원가입(카카오 로그인), 카드 서버 저장, 예약 관리 기능을 시작하면 수집 항목·보관 기간·파기 방법·처리 위탁을 적은 새 방침을 시행 7일 전에 이 페이지에 알려 드려요.
